# 에이전트 자동업데이트 후 "세션별로 증상이 다름" — 옛 프로세스 잔재

## 증상 패턴

같은 에이전트인데 **어떤 세션은 버그가 있고 어떤 세션은 정상** — 불규칙해 보이지만 실제로는:

- 에이전트 CLI(codex 등)는 **세션마다 별도 프로세스**다.
- DevezCode 자동업데이트(또는 npm -g 갱신)가 디스크의 바이너리를 바꿔도,
  **이미 실행 중인 세션 프로세스는 옛 버전으로 계속 돈다**(핫스왑 불가).
- → 업데이트 시점 이전에 연 세션 = 옛 버전(버그), 이후 세션 = 새 버전(정상). 혹은 그 반대.

## 판별법

1. 디스크 버전·갱신 시각 확인: `codex --version` + `npm 전역 node_modules/@openai/codex` mtime.
2. **새 세션을 하나 열어** 재현 여부 확인:
   - 새 세션 정상 + 기존 세션만 이상 → 옛 프로세스 잔재. **문제 세션 재시작으로 해결. 코드 수정 금지.**
   - 새 세션도 이상 → 새 버전의 회귀. 그때 changelog 대조·보정 검토.
3. changelog: https://developers.openai.com/codex/changelog (→ learn.chatgpt.com/docs/changelog 리다이렉트),
   GitHub releases: openai/codex.
