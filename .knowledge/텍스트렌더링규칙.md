# 텍스트 렌더링 규칙 (글자 깨짐 방지)

새 UI(텍스트 표시/입력 컨트롤)를 추가할 때 반드시 이 규칙을 따른다.
한글(Pretendard) 글자가 깨져 보이는 현상을 막기 위한 전역 설정이다.

## 전역 설정 구조

- `App.xaml`의 `Window` 기본 스타일이 `TextOptions.TextFormattingMode="Display"`를 모든 자식에 상속시킨다.
- `Styles/AppStyles.xaml`의 전역 스타일이 아래 3개 컨트롤을 `Ideal + ClearType`로 오버라이드한다.
  - `TextBlock` 전역 스타일
  - `TextBox` 전역 스타일
  - `RichTextBox` 전역 스타일

→ 따라서 `TextBlock` / `TextBox` / `RichTextBox`를 **스타일 없이** 그냥 쓰면 자동으로 `Ideal`이 적용된다(올바름).

## 지켜야 할 것

1. **keyed 스타일에는 반드시 `BasedOn` 을 건다.**
   `TargetType="TextBlock|TextBox|RichTextBox"` 인 명명(x:Key) 스타일은 `BasedOn` 이 없으면
   전역 스타일을 **통째로 대체**해서 `Ideal` 설정을 잃고 `Display` 를 상속 → 글자 깨짐.

   ```xml
   <!-- 나쁨: 전역 Ideal 유실 -->
   <Style x:Key="FieldLabel" TargetType="TextBlock">

   <!-- 좋음 -->
   <Style x:Key="FieldLabel" TargetType="TextBlock"
          BasedOn="{StaticResource {x:Type TextBlock}}">
   ```

   TextBox 파생 스타일도 동일: `BasedOn="{StaticResource {x:Type TextBox}}"` 또는
   기존 `InputStyle` 등을 `BasedOn` 으로 잇는다.

2. **devez 정합 인라인 설정.** devez 채팅 텍스트박스처럼 개별 컨트롤에 명시할 때는
   `TextOptions.TextFormattingMode="Ideal"` + `TextOptions.TextRenderingMode="ClearType"` 를 함께 쓴다.

3. **`Display` 를 새로 명시하지 말 것.** `Display` 명시는 `App.xaml` 전역 기본값 한 곳으로 충분하다.

## 점검 방법

- keyed `TextBlock|TextBox|RichTextBox` 스타일 중 `BasedOn` 없는 것 검색 → 발견 시 `BasedOn` 추가.
- 새 텍스트 컨트롤은 전역 스타일을 타도록 두거나, 위 인라인 설정을 명시.
