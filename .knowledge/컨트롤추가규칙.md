# 컨트롤 추가 규칙

버튼·카드·리스트 행 등 클릭 가능한 UI를 추가할 때 반드시 이 규칙을 따른다.

## 커서 (필수)

- **항상 `Arrow` 커서를 쓴다.** `Hand`(손가락) 커서는 사용하지 않는다.
- XAML: `Cursor="Arrow"` 또는 스타일에서 `<Setter Property="Cursor" Value="Arrow"/>`
- 코드비하인드: `Cursor = Cursors.Arrow` (또는 `Cursors.Hand` 금지)

```xml
<!-- 나쁨 -->
<Button Cursor="Hand" .../>
<Border Cursor="Hand" MouseLeftButtonUp="..."/>

<!-- 좋음 -->
<Button Cursor="Arrow" .../>
<Border Cursor="Arrow" MouseLeftButtonUp="..."/>
```

```csharp
// 나쁨
btn.Cursor = Cursors.Hand;

// 좋음
btn.Cursor = Cursors.Arrow;
```

### 예외

- **리사이즈 핸들**만 방향 커서 허용: `SizeWE`, `SizeNS` 등 (스플리터·패널 경계).
- 그 외 클릭·호버 가능 컨트롤(Button, RadioButton, Border 카드, TextBlock 링크 스타일 등)은 전부 `Arrow`.

### 점검

- 새/수정 XAML·CS에서 `Cursor="Hand"` / `Cursors.Hand` 검색 → 있으면 `Arrow`로 교체.
- `Styles/AppStyles.xaml` 공통 버튼 스타일(`PrimaryButton`, `SecondaryButton`, `IconButton`, `TitleBarChipButton` 등)도 `Arrow`를 유지한다.
