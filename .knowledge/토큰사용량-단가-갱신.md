# 토큰 사용량 비용($) 단가 — 갱신 프로세스

> 세션 헤더의 토큰 사용량 표시(`↓입력 ↑출력 ($비용)`)에서 **비용($) 을 계산하는 모델별 단가**를 바꾸거나
> 새 모델을 추가할 때 보는 문서. "단가 최신화 해줘", "gpt-5.6 단가 넣어줘", "opus 값 바꿔" 등에 이 절차를 따른다.

## 구조 (어디서 뭐가 계산되나)

| 요소 | 위치 | 비고 |
|---|---|---|
| **토큰 집계·비용 계산** | `Services/SessionUsageService.cs` | `ParseClaudeFull`(claude, message.id dedup)·`ReadCodex`(codex). **모델별 버킷**으로 단가 합산 → 세션 중 모델 변경도 정확 |
| **내장 기본 단가표** | `SessionUsageService.PriceFor()` | 문자열 `contains` 매칭, **구체적 모델 먼저**(gpt-5.6-terra → gpt-5.6 → gpt-5 순). fable/opus/sonnet/haiku/gpt-5.6(sol·terra·luna)/gpt-5.5/gpt-5.3-codex/gpt-5 |
| **외부 단가(우선)** | `settings.json` 의 `UsagePricing` 배열 | `SettingsService.LoadUsagePricing()`. 있으면 내장값보다 **우선**(덮어쓰기/신규 추가). **재빌드 불필요** |
| **캐시 배수** | 규칙별(`UsagePriceRule.CacheWrite5m/1h/Read`) → 없으면 표준 기본 | 표준 = write 5m ×1.25, 1h ×2, read ×0.1 (입력 단가 대비). 기본 상수 = `SessionUsageService.DefW5m/DefW1h/DefRead`. 공급자/모델별로 다르면 규칙에서 덮어씀 |
| **모델 라벨 축약** | `ShortModel()` | 툴팁/혼합표시용 |

- 단가 단위: **100만 토큰당 달러**(perM).
- **토큰 수는 로그 실측값**(하드코딩 아님). **단가만** 가변.
- Claude 단가 = `claude-api` 스킬(공시가) 기준 정확. Codex(GPT)도 2026-07 공시가 반영(티어별 정확).
- **Codex 캐시 write**: GPT-5.6부터 cache write ×1.25 과금 — `ReadCodex` 가 `cache_write_input_tokens` 를
  `CacheWrite5m` 버킷으로 파싱(표준 5m 배수 1.25 와 동일해 공식 재사용). 구 GPT-5 는 이 필드가 0.

## 갱신 방법

### 방법 A — settings.json 만 수정 (권장, 재빌드 불필요)

`%AppData%\DevezCode\settings.json` 의 `UsagePricing` 배열을 편집. 앱 재시작이면 반영(설정 재로드).
위에서부터 먼저 맞는 규칙 사용하므로 **더 구체적인 모델을 위에** 둔다.

```json
"UsagePricing": [
  { "Match": "gpt-5.6", "InPerM": 1.75, "OutPerM": 12, "CacheRead": 0.25 },
  { "Match": "opus",    "InPerM": 5,    "OutPerM": 25 },
  { "Match": "sonnet",  "InPerM": 3,    "OutPerM": 15 }
]
```

- `Match`: 모델ID **부분일치**(소문자 비교). 예 `"opus"` 는 `claude-opus-4-8` 매칭, `"gpt-5"` 는 `gpt-5.6-sol` 매칭.
- `CacheWrite5m`/`CacheWrite1h`/`CacheRead`: **생략하면 표준값**(1.25/2/0.1). 캐시 요율이 다른 모델만 명시(위 예: gpt-5.6 의 cached read 만 0.25 로 덮어씀).
- 배열이 비어 있으면 내장 기본값 사용.
- 설정에 있는 항목은 내장값을 덮어쓴다(신규 모델은 그냥 추가).

### 방법 B — 내장 기본값 수정 (코드)

`SessionUsageService.PriceFor()` 의 내장 `if (m.Contains(...)) return new Price(in, out, DefW5m, DefW1h, DefRead);`
라인 수정/추가. 공시가 변동 반영이나 기본 동봉값 갱신 시. 표준 캐시배수를 통째 바꾸려면 `DefW5m/DefW1h/DefRead`
상수 수정. 수정 후 빌드·커밋.

### ★ 단가 갱신 시 반드시 함께 점검 — 캐시 배수

단가(InPerM/OutPerM)만 보지 말고 **캐시 요율도 확인**한다:
1. **입력·출력 단가** 최신값 (아래 "확인처")
2. **캐시 write 배수** — Anthropic 5m ×1.25 / 1h ×2 유지되는지
3. **캐시 read 배수** — Anthropic ×0.1, OpenAI cached input 비율(현재 ×0.1 가정)이 그대로인지
4. 공급자별로 read 배수가 달라졌으면 해당 규칙에 `CacheRead` 등 명시(방법 A) 또는 상수 조정(방법 B)

캐시 배수가 틀리면 캐시 비중이 큰 세션에서 금액이 크게 어긋난다(캐시 read/write 가 비용의 대부분).

## 최신 단가 확인처

- **Claude**: `claude-api` 스킬의 모델 표(또는 platform.claude.com/docs pricing). Opus $5/$25, Sonnet $3/$15
  (인트로 $2/$10 은 2026-08-31 까지 — 내장표는 정가 기준), Haiku $1/$5, Fable $10/$50.
- **GPT(Codex)**: OpenAI 공식 pricing. 2026-07 반영값 — gpt-5.6-sol $5/$30, terra $2.5/$15, luna $1/$6
  (cached read ×0.1, cache write ×1.25), gpt-5.5 $5/$30, gpt-5.3-codex $1.75/$14, 구 gpt-5 계열 $1.25/$10.

## 주의

- 캐시 배수(1.25/2/0.1)는 현행 표준값. 규칙별로 `CacheWrite5m/1h/Read` 로 덮어쓰거나(설정) `DefW5m/DefW1h/DefRead` 상수로 전역 변경(코드).
- 비용은 **API 정가 환산 추정치**. 구독(Max/Pro)으로 쓰면 실제 청구 아님(툴팁 안내 문구 참고).
- 단가 미상 모델(매칭 실패)은 비용에서 제외(0 기여) — 토큰만 표시되고 $ 는 생략된다.
