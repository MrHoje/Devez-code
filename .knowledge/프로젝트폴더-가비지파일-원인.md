# 프로젝트 폴더에 코드조각 이름의 가비지 파일이 생기는 원인

## 증상
작업 중인 프로젝트 폴더(cwd)에 이상한 이름의 **0바이트 파일**이 계속 쌓인다. 이름이 그 프로젝트의 **소스 코드 조각**이다.

예: `0`, `,`, `,+`, `'`, `token)`, `!IsRefreshing`, `string.IsNullOrEmpty(code)`, `SaveTabOrder()`, `_timer.Stop()`, `Navigate(typeof(QaBranchPage)`, `1500)`, `col`, `all`, `Get(key`.

## 원인 (확정) — DevezCode 아님, **Claude Code 의 Bash 툴**
claude 가 코드베이스에 대해 셸 명령을 실행할 때, C# 코드의 `>` · `=>` · `,` 같은 문자가 **git-bash 에서 리다이렉트/연산자로 해석**되어 cwd(=프로젝트)에 파일을 만든다. claude 의 Bash 툴 서브프로세스가 cwd=프로젝트로 돌기 때문에 프로젝트 폴더에 쌓인다.

재현되는 두 패턴:
```bash
# 패턴1 — 명령에 C# 조각이 인용 안 된 채 들어감 (=>, > 가 리다이렉트로)
grep -rn public bool X => !IsRefreshing src      # → 파일 "!IsRefreshing"
somecmd > col                                     # → 파일 "col"

# 패턴2 — 코드 분석 루프가 매치를 인용 타깃으로 리다이렉트 (괄호 이름은 이 경로로만)
grep -oE '[A-Za-z_.]+\([^)]*\)' file.cs | while read -r m; do : > "$m"; done
# → "SaveTabOrder()", "_timer.Stop()", "string.IsNullOrEmpty(code)"
```
괄호(`(`,`)`) 든 이름은 bash 에서 unquoted 면 **문법오류라 안 생긴다** → 반드시 패턴2(인용 타깃) 경로. 괄호 없는 이름은 패턴1.

## DevezCode 가 아닌 근거 (전부 반증)
- **붙여넣기/작업 큐 아님**: 작업 큐 미사용·비어있음. 붙여넣기 가드 있어도 발생.
- **호스팅 `cmd /k` 아님**: claude 가 포그라운드로 돌 때(맨 셸 아닐 때) 발생.
- **DevezCode 훅 아님**: `busy-hook.ps1` / `room-statusline.js` 는 전부 `%APPDATA%\DevezCode\claude\` 하위 고정경로 + `[^\w\-]` sanitize 로 씀. cwd 에 안 씀.
- **빌드 이벤트 아님**: 프로젝트에 PreBuild/PostBuild/Exec 없음.
- **결정적 증명**: 세션을 **외부 Windows Terminal**(DevezCode 호스팅 없음)로 옮겨도, claude 식 명령이 실제 프로젝트 루트에 동일 가비지를 만든다 → 호스트 무관 = claude/git-bash.

- 청소:
```bash
# 0바이트 + 셸메타/코드조각 이름만 (정상파일 보호). git 추적 안 되는 것만.
git status --porcelain -uall | grep '^??' | ...   # 확인 후
find . -maxdepth 1 -type f -size 0 -name '*[()<>|&,+]*' -delete
```
