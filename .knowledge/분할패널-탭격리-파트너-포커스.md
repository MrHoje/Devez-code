# 중앙 2분할(Split) 패널 — 탭 격리·파트너 영속·포커스·터미널 재진입

## 구조 한 줄 요약
중앙은 `PaneA`/`PaneB` 두 개의 `WorkspacePaneView`. 각 패널은 **자기 WebView2 터미널**과
**자기 활성 프로젝트/세션/탭**을 갖는 독립 단위. `LeftPane`/`RightPane` 은 `_panesSwapped` 로
물리 컬럼(col0/col2)에 매핑된다(스왑 시 뒤바뀜). 분할은 `MainWindow._splitActive`.

핵심 어려움: **두 패널이 같은 `ProjectItem.Tabs`(공유 컬렉션)를 동시에 볼 수 있다.**
"분할 보기/이동"으로 한 세션·파일만 우측에 띄우는 게 대표 시나리오. 그래서 "어느 탭을 어느
패널에 보일지", "선택 표시", "포커스", "영속" 이 전부 패널별로 갈라져야 한다.

---

## 1. 탭 표시 필터 (패널별) — WorkspacePaneView
공유 `Tabs` 를 패널마다 다르게 보이려고 `ListCollectionView` 필터를 쓴다. 모드 2개:
- `_hiddenFromThisPane`(HashSet, **블랙리스트**): 전체 표시 모드에서 특정 탭만 숨김.
- `_isolatedTabs`(HashSet?, **화이트리스트**): null 이 아니면 이 집합의 탭만 보임(격리 모드).

`FilterTab`: `_isolatedTabs != null ? contains : !hidden`.

### 함정
- **화이트리스트가 비어도 절대 `null`(전체모드)로 되돌리지 마라.** 되돌리면 같은 프로젝트를
  공유하는 반대쪽 패널의 전체 탭이 갑자기 다 보인다. 마지막 격리 탭까지 빠지면 빈 탭바가 맞다.
- 격리는 **휘발성(뷰 상태)**. 프로젝트를 떠나면(`ApplyTabsSource` 리셋) 사라진다 → 재진입 시
  파트너 영속값으로 **재현**해야 한다(아래 3번).
- `HideTabInPane`: 숨긴 탭이 그 패널의 활성 탭이면 **다른 탭으로 교체**해야 한다. 안 하면
  `_activeTab` 이 넘어간 탭을 계속 가리켜, 그 탭을 다시 그 패널로 "이동"할 때
  `target.ActiveTab==tab` 오판으로 조기 반환된다(파일 탭은 세션과 달리 소유권 라우팅이 없어 특히 취약).
- 격리 모드에서 탭을 숨길 땐 블랙리스트가 아니라 **화이트리스트에서 제거**.

## 2. 탭 "이동"(분할 보기/오른쪽·왼쪽으로 이동) — MainWindow.OnPaneSplitViewRequested
- 같은 프로젝트로 이동: 대상의 **선택 탭을 바꾸지 않는다**(OpenSession 안 부르고 `UnhideTabInPane`만).
  요구사항: "이동 탭이 반대쪽 선택 탭을 변경하면 안 됨."
- 다른 프로젝트/빈 패널로 이동: 프로젝트 전환 불가피 → 이동 탭만 `IsolateTab`(그 탭만 표시).
- 이동한 탭은 `MoveTabToEnd` 로 그 프로젝트 탭 목록 맨 끝으로(대상 탭바 오른쪽 끝) + `ScrollTabIntoView`.

## 3. 분할 영속 = 프로젝트 단위 (ProjectItem, workspace.json)
분할은 **프로젝트별**로 기억한다(A는 분할, B는 단일 가능):
- `SplitEnabled`: 이 프로젝트를 메인(좌측)에 열 때 분할을 켤지.
- 파트너(우측 내용): `SplitPartnerSessionId`(세션) → `SplitPartnerFilePath`(파일) → `SplitPartnerProjectPath`(다른 프로젝트) 우선순위.

### 결정적 함정 (이번 세션 최대 버그)
우측 패널이 **파일 탭**이면 `RightPane.ActiveSession == null` 이라, 세션ID만 저장하던 초기 구현은
`SplitPartnerSessionId=null` + `SplitPartnerProjectPath=자기자신` 을 저장했다. 복원 시
`ResolveSplitPartner` 가 **자기 프로젝트를 우측에 통째로(full)** 열어 → **양쪽 패널에 전 세션 중복**.
→ 해결: 우측이 파일이면 `SplitPartnerFilePath` 저장, 복원 시 우측에 그 파일을 열어 격리.
`ResolveSplitPartner` 는 자기자신 통째 파트너를 무효화(중복 방지).

- `PersistSplitState`: `_splitActive && leftProj.SplitEnabled` 일 때만 파트너 갱신. 우측이 세션이면
  SessionId, 파일이면 FilePath(다른 쪽 null).
- `RestorePartner`(런타임 전환)와 `RestoreSplitState_AfterLayout`(재시작) **둘 다** 같은 프로젝트
  격리 재현 로직이 필요하다. 한쪽만 고치면 다른 경로에서 재발.
- 프로젝트 전환 시 분할 열기/닫기는 **애니메이션 생략**(`EnableSplit/DisableSplit(animate:false)`).
  버튼 토글로 직접 여닫을 때만 슬라이드.

## 4. 패널별 탭 "선택" 표시 — 공유 IsSelected 금지
`TabItemBase.IsSelected`(공유 bool)로 선택 강조를 하면, 두 패널이 같은 프로젝트를 볼 때 한쪽
활성화가 반대쪽 선택을 덮어써 비포커스 패널 선택 표시가 사라진다.
→ 패널별 `SelectedTab`(DependencyProperty) + 탭 템플릿에서 `MultiBinding(탭 아이템 vs 패널.SelectedTab)`
+ `TabActiveConverter` 로 판정. `WorkspacePaneView.xaml` 의 3개 선택 트리거 모두 이 방식.
`_activeTab` 은 DP 백킹 프로퍼티라 기존 대입이 자동으로 DP 갱신.

## 5. 포커스 테두리 — airspace 우회 (터미널·파일 에디터 공통)
WebView2(터미널/md 에디터)는 HwndHost 라 그 위 클릭이 WPF `PreviewMouseDown` 로 안 온다
(airspace). 그래서 각 웹 레이어가 클릭 시 `interact` 메시지를 post → C# 이벤트 → `FocusRequested`.
- 터미널: `TerminalHostView.UserInteracted`.
- md 에디터: `bridge.js` `pointerdown`(capture) → `MarkdownWysiwygHost.Interacted` → `IFileTabEditor.Interacted`.

### 함정 (이번 세션 버그)
파일 에디터 UserControl 은 `FileTabItem` 당 **공유 단일 인스턴스**. `Interacted → FocusRequested(this)`
를 **탭 생성 패널**에서 구독하면, 그 탭이 다른 패널에서 표시·클릭될 때 생성 패널이 잘못 포커스된다
(우측에서 만든 파일 → 좌측에서 클릭해도 우측이 포커스).
→ 구독을 `ActivateFileTab`(표시 패널)에서 `_activeTab==tab` 가드로, 패널당 1회(dedup) 건다.

## 6. 터미널 재진입 리플로우 — 폭 잘림 (WebView2 per-pane)
패널마다 WebView2 가 따로다. 세션이 패널 간 이동(또는 분할 재진입)하면 **새 xterm 인스턴스**가
생겨 ConPTY 에 재배선된다(`WireSession` reattach). 두 가지 증상:
- **내용 오른쪽 잘림**: `show()` 시점엔 WebView2 컨테이너가 최종 픽셀 폭 도달 전 → 첫 `fit()` 이
  좁은 cols 로 굳음. → `terminal.html show()` 에 **지연 재-fit**(`refitSoon`: rAF² + 60ms + 180ms)
  으로 레이아웃 안정 후 재측정, `onResize` 가 ConPTY 로 정확한 크기 전파 → alt-screen TUI 풀폭 재렌더.
- **스크롤 위로 안 됨**: claude 등 alt-screen TUI 는 스크롤백이 없음 → 버그 아님.
- 재진입 스피너 잠깐/재렌더: ConPTY 스크롤백은 리사이즈로 현재 화면만 재방출되므로, 세션을 새
  xterm 으로 옮기면 과거 스크롤백은 복원 불가(구조적 한계).

### reattach resize 킥 (TerminalHostView.WireSession)
`session.HasPriorOutput && !ready` 면 준비 복원 + 리사이즈. 새 xterm 크기가 세션 마지막 크기와
**다르면** 정상 리사이즈 1회(자연 리페인트). **같을 때만** `-1 후 원복` 킥으로 강제 SIGWINCH.
매번 -1/+1 을 걸면 그 리플로우 왕복이 줄바꿈/잘림을 유발(패널 왕복 누적) — 조건부로만.

## 7. 출력 핸들러 detach — "글자 두 번 입력"의 실체
`WireSession` 이 `session.OutputReceived += ...` 구독. `CloseTerminal`/재배선 시 **반드시 detach**
(`_sessionHandlers` 로 추적). 안 하면 패널 왕복으로 같은 세션에 핸들러가 누적 → 출력이 2·3배
중복 post → 화면에 글자가 여러 번 찍힌다(사용자는 "두 번 입력"으로 인지). 입력 중복이 아니라 출력 중복.

## 8. WebView2 정적 자산 캐시버스팅 (필수)
가상호스트로 서빙하는 html/js 는 WebView2 HTTP 캐시에 남아, 파일을 고쳐 재빌드해도 **옛 버전이
로드**된다. `terminal.html` 은 `?v={ticks}` 로 무력화. `editor.html` 은 이게 없어 `bridge.js` 변경이
안 먹던 버그가 있었음 → `editor.html?v={ticks}` + editor.html 이 그 쿼리를 `bridge.js` <script> 에
전파(동적 로더)하도록 수정. **새 웹 자산/스크립트를 추가하면 캐시버스팅을 빠뜨리지 말 것.**

## 9. 파일 탭 닫기 = 생성 패널이 아니라 '표시 패널'로 라우팅 (§5 의 형제 버그)
파일 에디터는 `FileTabItem` 당 **공유 단일 인스턴스**(§5). `CreateFileTab` 에서 `CloseRequested`
를 곧바로 `RemoveFileTab(tab)` 로 **탭 생성 패널(this)** 에 묶으면, 파일을 좌측에서 열고 "분할 보기"로
우측에 옮긴 뒤 닫을 때 **생성 패널(좌측)** 의 RemoveFileTab 이 돈다. 좌측에선 그 파일이 활성이
아니라 `wasActive=false` → 이웃 선택 안 함, 우측(실제 표시)은 갱신 안 됨 → **우측에 세션+md 가
있을 때 md 를 닫아도 이웃 세션이 선택되지 않고 md 타이틀이 그대로 남는다.**
→ 에디터 `CloseRequested` 를 패널이 직접 처리하지 말고 `FileTabCloseRequested` 이벤트로 셸에
위임한다. 셸 `OnFileTabCloseRequested` 가 **활성 표시 패널(`ActiveTab==tab`) → `ShowsTab` → 포커스
패널** 순으로 라우팅해 그 패널에서 `CloseFileTab`(→`RemoveFileTab`). 탭 X·에디터 내부 닫기 버튼·
우클릭 "닫기/다른 파일 모두 닫기" 가 전부 이 경로로 통일된다.
- §5(Interacted)와 **정확히 같은 뿌리**: "공유 에디터 구독을 생성 패널에 걸면 오작동."
  **새 에디터 이벤트를 추가할 때는 항상 '표시 패널로 라우팅해야 하는가'를 먼저 따져라.**

## 10. 분할 중 포커스 패널이 비면 반대 패널로 포커스 이양
분할에서 포커스 패널의 마지막 탭을 닫아 활성 탭이 없어지면(`ClearActiveSession`) 포커스가 빈
패널에 그대로 남아, 내용이 남은 반대 패널의 세션이 선택되지 않고 셸(사이드바·헤더 타이틀)이
갱신되지 않는다(우측 유일 파일을 닫았을 때 좌측 세션 미선택).
→ `OnPaneActiveChanged`: `_splitActive && pane==_focusedPane && pane.ActiveTab==null` 이면 내용이
남은(`ActiveTab!=null`) 반대 패널로 `_focusedPane` 을 이양하고 `SyncShellToFocusedPane`+`UpdatePaneFocusVisual`.
`_splitActive` 가드가 분할 해제/전환(그때도 ClearForHide 로 패널이 비지만 `_splitActive` 는 이미 false)
중의 오발동을 막는다. §9(표시 패널 라우팅)로 이웃 세션이 있으면 그쪽이 먼저 선택되고, 이웃이 없어
정말 빌 때만 이 이양이 동작한다.

## 제거된 구 UI (참고)
드래그-드롭 분할 오버레이(`SplitDropOverlayWindow`/`DragGhostWindow`), 상단 타이틀바 분할 버튼,
프로젝트 카드 좌/우 패널 배지(PaneRole), 프로젝트 타겟 피커(`ProjectTargetPickerWindow`) 는 전부 제거됨.
현재 분할 진입/이동은 **탭 우클릭 메뉴 + 탭바 우측 dock 토글 버튼**만 사용.
