# 탭바 생성 규칙 — devezCode WorkspacePaneView 기준

## 한 줄 요약

`ItemsControl` 바인딩 기반 탭바(TabBar)에 `CornerRadius="9,9,0,0"`인 개별 탭(TabBd)이 DataTemplate으로 렌더링된다.
선택 탭은 `TabActiveConverter` MultiBinding으로 판정하며, 하단 좌우 라운드 틈새를 Feet Paths로 채워
콘텐츠 영역과 연결(connected)된 것처럼 보이게 한다.
드래그 재정렬은 ReorderDrag(고스트+시프트 애니메이션)로 처리하며,
드래그 중에는 편집 중이 아닌 탭의 Seam을 TranslateTransform으로 따라가게 하고,
드래그하는 탭의 Feet은 HideTabFeet으로 숨긴다.

## 2. XAML 속성 의미

| 속성 | 값 | 이유 |
|------|-----|------|
| `CanContentScroll="False"` | False | 픽셀 단위 스크롤 필수. True면 아이템 단위 스크롤 → `TransformToAncestor` 좌표 계산이 깨짐 |
| `Background="{x:Null}"` | null | ScrollViewer 배경이 불투명 흰색으로 칠해져 TabBar 배경을 가리는 것 방지 |
| `IsHitTestVisible="False"` (Seam) | False | seam이 마우스 이벤트를 가로채 탭 클릭을 방해하지 않도록 |
| `Padding="0,4,12,0"` (TabBar) | 우측 12px | 우측 버튼 영역과 탭 사이 여유 |
| `Padding="11,0,0,0"` (TabsHost) | 좌측 11px | 첫 탭 앞 여백 |

## 3. TabItemBase 타입 계층

```csharp
// Models/WorkspaceModels.cs — 추상 기본 클래스 (별도 파일 아님)
public abstract class TabItemBase : NotifyBase
{
    public string Id { get; init; }              // GUID
    public abstract string Title { get; }         // 파일명/세션명
    public abstract TabKind Kind { get; }         // Session | File | Browser — DataTrigger로 아이콘 전환
    public bool IsSelected { get; set; }
    public bool Hidden { get; set; }              // true → DataTrigger가 Visibility=Collapsed (세션 탭 전용)
}

// 세션 탭 (Kind = TabKind.Session)
public sealed class SessionItem : TabItemBase
{
    public bool IsAlive, IsBusy, IsWaitingChoice;
    public string? AgentId;  // AgentImageConverter로 아이콘
}

// 파일 탭 (Kind = TabKind.File)
public sealed class FileTabItem : TabItemBase
{
    public string FilePath { get; init; } = "";
    public IFileTabEditor Editor { get; init; } = new FileEditorView();
}

// 브라우저 탭 (Kind = TabKind.Browser) — 탭마다 독립 WebView2
public sealed class BrowserTabItem : TabItemBase
{
    public BrowserHostView Browser { get; init; } = new();
}
```

### 활성 탭 판정: TabActiveConverter

`TabActiveConverter`는 `IMultiValueConverter`로, 현재 탭 아이템과 `SelectedTab` DP를 비교한다.

```xml
<!-- ContentPresenter에 ZIndex 상승 -->
<DataTrigger Value="True">
  <DataTrigger.Binding>
    <MultiBinding Converter="{x:Static models:TabActiveConverter.Instance}">
      <Binding/>                                  <!-- current item -->
      <Binding Path="SelectedTab"                 <!-- panel's selected tab -->
               RelativeSource="{RelativeSource AncestorType=v:WorkspacePaneView}"/>
    </MultiBinding>
  </DataTrigger.Binding>
  <Setter Property="Panel.ZIndex" Value="10"/>
</DataTrigger>
```

이 방식의 장점: **두 패널이 같은 프로젝트를 공유해도 각자 독립적으로 활성 탭을 판정**한다.
(기존 `TabItemBase.IsSelected` 공유 bool은 상대 패널 선택을 덮어써서 폐기됨.)

#### DataTrigger가 제어하는 속성들

| 트리거 | 조건 | 효과 |
|--------|------|-------|
| `TabActiveConverter=True` → TabTitle Foreground | 활성 | `TextBrush` |
| `TabActiveConverter=True` → TabBd Background | 활성 | `PanelBrush` (기본: `PanelSoftBrush`) |
| `TabActiveConverter=True` → Feet 4개 Path | 활성 | `Visibility=Visible` (기본: `Collapsed`) |
| `TabActiveConverter=True` → ContentPresenter ZIndex | 활성 | 10 |
| `IsMouseOver=True` → TabTitle Foreground | 호버 | `TextBrush` |
| `Binding Kind=File` → TabAgentIcon/FileIcon | 파일 탭 | 에이전트 아이콘 Collapsed, 파일 아이콘 Visible |
| `Binding Kind=Browser` → TabBrowserIcon | 브라우저 탭 | 에이전트 아이콘 Collapsed, 브라우저 아이콘 Visible |
| `IsWaitingChoice=True` | 입력 대기 | ❗ 아이콘 Visible |
| `IsBusy=True + IsWaitingChoice=False` | 처리 중 | 스피너 Visible |
| `Hidden=True` → TabRoot | 숨김 | `Visibility=Collapsed` |

## 4. TabBd — 탭 본체 (Border)

```xml
<Border x:Name="TabBd" Margin="0,0,0,-1"
        VerticalAlignment="Bottom" Padding="0,6"
        MinWidth="131" MaxWidth="248"
        CornerRadius="9,9,0,0"
        BorderThickness="1,1,1,0"
        BorderBrush="{DynamicResource LineBrush}"
        Cursor="Arrow"
        SnapsToDevicePixels="True"
        UseLayoutRounding="True"
        PreviewMouseLeftButtonDown="Tab_PreviewMouseLeftButtonDown"
        MouseLeftButtonUp="Tab_Click"
        PreviewMouseRightButtonUp="Tab_RightClick">
```

**핵심 파라미터:**

| 속성 | 값 | 이유 |
|------|-----|------|
| `CornerRadius` | `(9,9,0,0)` | 상단만 9px 라운드, 하단은 직각 → 콘텐츠 영역과 이어짐 |
| `Margin` | `(0,0,0,-1)` | 하단 1px TabBar border 영역까지 확장 |
| `BorderThickness` | `(1,1,1,0)` | 좌/우/상단 border만, 하단 border 없음 (Seam+Feet이 담당) |
| `SnapsToDevicePixels` | True | 서브픽셀 렌더링으로 1px border가 흐려지는 것 방지 |
| `UseLayoutRounding` | True | 소수점 레이아웃에서 좌/우 두께가 1~2px로 들쭉날쭉하지 않게 |

## 5. Feet Paths — 선택 탭 하단 라운드 틈새 채움

`TabBd`가 `CornerRadius(9,9,0,0)`이라 하단 좌우는 직각이지만,
탭 하단 모서리와 TabBar 하단 border 사이에 라운드 효과를 주기 위해
별도 Path를 `TabRoot`의 자식으로 추가한다.

### 좌측

```xml
<!-- FootLeftFill: 좌측 하단 삼각형 채움 -->
<Path x:Name="TabFootLeftFill"
      HorizontalAlignment="Left" VerticalAlignment="Bottom"
      Margin="-10,0,0,-1"
      Fill="{DynamicResource PanelBrush}"
      Data="M11,0 L10,0 A10,13 0 0 1 0,13 L11,13 Z"
      Visibility="Collapsed"/>

<!-- FootLeftLine: 좌측 라운드 border 선 -->
<Path x:Name="TabFootLeftLine"
      HorizontalAlignment="Left" VerticalAlignment="Bottom"
      Margin="-10,0,0,-1"
      Stroke="{DynamicResource LineBrush}" StrokeThickness="1"
      Data="M10,-3 L10,0 A10,13 0 0 1 0,13"
      Visibility="Collapsed"/>
```

### 우측

```xml
<!-- FootRightFill -->
<Path x:Name="TabFootRightFill"
      HorizontalAlignment="Right" VerticalAlignment="Bottom"
      Margin="0,0,-10,-1"
      Fill="{DynamicResource PanelBrush}"
      Data="M0,0 L1,0 A10,13 0 0 0 11,13 L0,13 Z"
      Visibility="Collapsed"/>

<!-- FootRightLine -->
<Path x:Name="TabFootRightLine"
      HorizontalAlignment="Right" VerticalAlignment="Bottom"
      Margin="0,0,-10,-1"
      Stroke="{DynamicResource LineBrush}" StrokeThickness="1"
      Data="M1,-3 L1,0 A10,13 0 0 0 11,13"
      Visibility="Collapsed"/>
```

### Feet Path 파라미터

| 속성 | 값 | 이유 |
|------|-----|------|
| Margin 좌/우 | `-10` | 탭 본체보다 10px 확장 → 라운드가 충분히 표현됨 |
| Margin 하단 | `-1` | TabBar border 영역까지 확장 |
| Data A10,13 | 반지름 10, 세로 13의 호 | 탭 높이에 맞춘 라운드 곡선 |
| Fill | `PanelBrush` | 활성 탭 배경색과 동일 |
| Visibility | `Collapsed` (기본) | DataTrigger로 활성 탭만 Visible |

### Z-order (하단→상단)

```
1. TabRoot (Grid)
2.   ├── FootLeftFill / FootRightFill   (채움, TabBar border 아래)
3.   ├── FootLeftLine / FootRightLine   (border 선)
4.   └── TabBd (Border)
5. TabBar Border.BorderBrush            (전체 하단 1px line)
6. SelectedTabSeam                       (ZIndex=100, 선택 탭만 덮음)
```

`Feet(2~3) < TabBd(4) < TabBar Border(5) < SelectedTabSeam(6)`

Feet이 TabBar border **아래**에 그려지고, 위를 SelectedTabSeam이 덮는다.
따라서 Feet 영역도 TabBar border가 보이지 않고 콘텐츠 영역과 자연스럽게 연결된다.

### UpdateSelectedTabSeam — 상세는 전용 문서 참조

위치·폭 계산(`seamExtra=9.15`, `ActualWidth-3`), 스크롤 경계 좌측 클램핑(`clampedLeft`),
양 끝 4px 투명 페이드 `LinearGradientBrush`(`f=min(0.45, 4/seamWidth)`, `Freeze()`)의
전체 코드·도식·실수 방지 체크리스트는 **`탭바-SelectedTabSeam-밑줄-그라데이션.md`가 원본**이다.
여기에 코드를 복제하지 않는다. (메서드는 `WorkspacePaneView.xaml.cs`의 `UpdateSelectedTabSeam()` — 메서드명으로 grep)

### 호출 시점

| 상황 | 호출 |
|------|------|
| 탭 전환 (`ActivateSession`/`ActivateFileTab`) | `SelectedTab` DP 변경 → DataTrigger 자동 반영 + `UpdateSelectedTabSeam()` |
| 탭 닫아서 마지막 탭 사라짐 | `ClearActiveSession()` → `UpdateSelectedTabSeam()` |
| TabScroller 스크롤 | `ScrollChanged` → `UpdateSelectedTabSeam()` |
| 테마 변경 | `OnThemeChanged_UpdateSeam` → `Dispatcher.BeginInvoke(UpdateSelectedTabSeam)` |
| 외부 탭 재배열 | `RefreshSelectedTabSeam()` → `Dispatcher.InvokeAsync(Loaded)` 지연 호출 |
| 탭 드래그 | `SetupDragSeam` → `_tabDragHidSeam=true`로 업데이트 차단 |

## 7. 탭 오버플로우 — <> 버튼 + 엣지 페이드(블러)

탭이 TabScroller 뷰포트를 넘치면(overflow) 좌/우 스크롤 버튼(`TabNavGroup`)이 나타나고,
잘리는 쪽 가장자리는 `TabScroller.OpacityMask`로 그라데이션 페이드 처리한다.

### 7.2 시각적 관계: 버튼과 엣지 페이드

```
TabBar 영역 (Grid.Column=0+1):
┌─────────────────────────────────────────────────┐
│ Grid.Column=0 (TabScroller)   │ Col=1 (btns)   │
│                               │                 │
│ [Tab1] [Tab2] [Tab3] ...  [+] │  ◄  ►  │ ⛶ │
│ ← OpacityMask 페이드 영역      │                 │
└─────────────────────────────────────────────────┘
```

- `OpacityMask`는 `TabScroller`(Grid.Column=0)에만 적용
- `TabNavGroup`(Grid.Column=1)은 별도 열 → 마스크 영향 없음, 버튼은 항상 완전 불투명
- `TabNavGroup` 자체 배경 없음 → 버튼 뒤로 TabBar 배경(BgBrush)이 그대로 보임
- `NewTabBtn`은 `TabScroller` **내부**(Grid.Column=0) → 페이드 영향을 받음
- `SplitDockBtn`도 Column=1 → 마스크 영향 없음. 분할 상태에 따라 아이콘/색상/툴팁 동적 변경 (RefreshSplitIndicator)
- `NewTabBtn`은 초기 `Visibility="Collapsed"`, 프로젝트 활성화 시 Visible, 드래그 중 재Collapsed

### 7.3 UpdateTabOverflowButtons

```csharp
private void UpdateTabOverflowButtons()
{
    if (TabScroller == null || TabNavGroup == null) return;
    bool overflow = TabScroller.ScrollableWidth > 0.5;
    bool canLeft = TabScroller.HorizontalOffset > 0.5;
    bool canRight = TabScroller.HorizontalOffset < TabScroller.ScrollableWidth - 0.5;

    TabNavGroup.Visibility = overflow ? Visibility.Visible : Visibility.Collapsed;
    if (TabScrollLeftBtn != null) TabScrollLeftBtn.IsEnabled = canLeft;
    if (TabScrollRightBtn != null) TabScrollRightBtn.IsEnabled = canRight;

    ApplyTabEdgeFade(canLeft, canRight);
}
```

| 상태 | 조건 | 동작 |
|------|------|------|
| overflow=false | ScrollableWidth ≤ 0.5 | TabNavGroup Collapsed, OpacityMask=null |
| overflow=true, canLeft | Offset > 0.5 | ← Enabled, 좌측 페이드 |
| overflow=true, canRight | Offset < ScrollableWidth - 0.5 | → Enabled, 우측 페이드 |
| canLeft=false | Offset ≤ 0.5 | ← Disabled, 좌측 페이드 해제 |
| canRight=false | Offset ≥ ScrollableWidth - 0.5 | → Disabled, 우측 페이드 해제 |

### 7.4 ApplyTabEdgeFade — 엣지 블러(OpacityMask)

```csharp
private void ApplyTabEdgeFade(bool fadeLeft, bool fadeRight)
{
    double w = TabScroller.ActualWidth;
    if (_fadeLeft == fadeLeft && _fadeRight == fadeRight && Math.Abs(_fadeWidth - w) < 0.5)
        return;  // 상태 동일 + 폭 변화 없으면 스킵
    _fadeLeft = fadeLeft; _fadeRight = fadeRight; _fadeWidth = w;

    if (!fadeLeft && !fadeRight) { TabScroller.OpacityMask = null; return; }

    double f = Math.Min(0.10, 28 / Math.Max(1, w));
    var mask = new LinearGradientBrush { StartPoint = new Point(0, 0), EndPoint = new Point(1, 0) };
    var black = Colors.Black;
    var clear = Colors.Transparent;
    mask.GradientStops.Add(new GradientStop(fadeLeft ? clear : black, 0));
    mask.GradientStops.Add(new GradientStop(black, fadeLeft ? f : 0));
    mask.GradientStops.Add(new GradientStop(black, fadeRight ? 1 - f : 1));
    mask.GradientStops.Add(new GradientStop(fadeRight ? clear : black, 1));
    mask.Freeze();
    TabScroller.OpacityMask = mask;
}
```

**파라미터:**

| 변수 | 값 | 의미 |
|------|-----|------|
| `f` | `min(0.10, 28 / width)` | 페이드 폭 비율. 28px 고정 폭을 뷰포트 width로 나눔, 최대 10% |
| `fadeLeft/fadeRight` | bool | 스크롤 가능 방향 = 페이드 적용 방향 |

**그라데이션 구조 (좌→우):**
```
fadeLeft=true:
  0%          f%                             100%
  │◄──fade──►│◄──────── solid ──────────────►│
  Transparent Black                           Black

fadeRight=true:
  0%                             1-f%       100%
  │◄──────── solid ────────────►│◄──fade──►│
  Black                          Black       Transparent
```

```csharp
// 버튼 — 240ms EaseInOut 애니메이션 (TabScrollStep=168)
private const double TabScrollStep = 168;

private void TabScrollLeft_Click(object sender, RoutedEventArgs e)
    => AnimateTabScroll(TabScroller.HorizontalOffset - TabScrollStep);

private void TabScrollRight_Click(object sender, RoutedEventArgs e)
    => AnimateTabScroll(TabScroller.HorizontalOffset + TabScrollStep);

// AnimateTabScroll: CompositionTarget.Rendering 기반 240ms EaseInOut
private void AnimateTabScroll(double to)
{
    to = Math.Clamp(to, 0, TabScroller.ScrollableWidth);
    _tabScrollAnimCancel?.Invoke();
    var from = TabScroller.HorizontalOffset;
    if (Math.Abs(to - from) < 0.5) return;
    var sw = Stopwatch.StartNew();
    const int dur = 240;
    bool cancelled = false;
    EventHandler? handler = null;
    handler = (_, _) =>
    {
        if (cancelled) { CompositionTarget.Rendering -= handler!; return; }
        var t = Math.Min(1.0, sw.ElapsedMilliseconds / (double)dur);
        TabScroller.ScrollToHorizontalOffset(from + (to - from) * EaseInOut(t));
        if (t >= 1.0) CompositionTarget.Rendering -= handler!;
    };
    CompositionTarget.Rendering += handler;
    _tabScrollAnimCancel = () => { cancelled = true; CompositionTarget.Rendering -= handler; };
}

private static double EaseInOut(double t) =>
    t < 0.5 ? 4 * t * t * t : 1 - Math.Pow(-2 * t + 2, 3) / 2;
```

### 8.4 TryStartTabDrag

```csharp
private void TryStartTabDrag(TabItemBase s)
{
    var coll = _activeProject?.Tabs;
    if (coll == null) return;
    var rows = new List<(TabItemBase, FrameworkElement)>();
    FrameworkElement? sourceBorder = null;
    FrameworkElement? selectedRoot = null;

    foreach (var t in coll)
    {
        if (TabsHost.ItemContainerGenerator.ContainerFromItem(t) is FrameworkElement fe
            && FindTabBorder(fe) is FrameworkElement border
            && VisualTreeHelper.GetParent(border) is FrameworkElement root)
        {
            rows.Add((t, root));
            if (ReferenceEquals(t, s)) sourceBorder = border;
            if (ReferenceEquals(t, _activeTab)) selectedRoot = root;
        }
    }
    if (sourceBorder == null || rows.Count < 2) return;
    _dragGhostWidth = sourceBorder.ActualWidth;

    _tabDrag = ReorderDrag<TabItemBase>.TryStart(
        coordHost: TabsHost,
        rows: rows,
        source: s,
        sourceElement: sourceBorder,
        onCommit: (tab, hostTarget, _) =>
        {
            var c = _activeProject?.Tabs;
            if (c != null)
            {
                int from = c.IndexOf(tab);
                if (from >= 0)
                {
                    int to = Math.Clamp(hostTarget, 0, c.Count - 1);
                    if (to != from) { c.Move(from, to); WorkspaceStore.Save(Projects); }
                }
            }
            return Task.CompletedTask;
        },
        exactFollow: true,       // 정밀 추적 모드
        horizontal: true,
        ghostSource: sourceBorder);

    if (_tabDrag != null)
    {
        _tabDidDrag = true;
        TabsHost.CaptureMouse();
        HideTabFeet(sourceBorder);
        SetupDragSeam(s, selectedRoot);
        SetPanesTabDragActive?.Invoke(true);
    }
    else _pendingTab = null;
}
```

### 8.8 HideTabFeet / RestoreTabFeet

드래그 중인 탭의 Feet Path 4개를 숨겨서 탭이 이동할 때 Feet 잔상이 남지 않게 한다.

```csharp
private void HideTabFeet(FrameworkElement sourceBorder)
{
    RestoreTabFeet();  // 이전 숨김 초기화
    var root = VisualTreeHelper.GetParent(sourceBorder);
    if (root == null) return;
    int n = VisualTreeHelper.GetChildrenCount(root);
    for (int i = 0; i < n; i++)
    {
        if (VisualTreeHelper.GetChild(root, i) is FrameworkElement
            { Name: "TabFootLeftFill" or "TabFootLeftLine"
                 or "TabFootRightFill" or "TabFootRightLine" } foot)
        {
            foot.Visibility = Visibility.Collapsed;
            _hiddenTabFeet.Add(foot);
        }
    }
}

private void RestoreTabFeet()
{
    foreach (var foot in _hiddenTabFeet)
        foot.ClearValue(UIElement.VisibilityProperty);
    _hiddenTabFeet.Clear();
    _tabDragHidSeam = false;
    if (SelectedTabSeam != null) SelectedTabSeam.RenderTransform = null;
    Dispatcher.InvokeAsync(UpdateSelectedTabSeam, DispatcherPriority.Loaded);
}
```

### 8.9 SetupDragSeam — 드래그 중 Seam 처리

활성 탭을 드래그하면 Seam을 완전히 숨기고,
비활성 탭을 드래그하면 Seam이 선택 탭 위치를 따라가도록 TranslateTransform을 건다.

```csharp
private void SetupDragSeam(TabItemBase source, FrameworkElement? selectedRoot)
{
    if (SelectedTabSeam == null) return;
    _tabDragHidSeam = true;  // UpdateSelectedTabSeam 스킵 플래그
    bool draggingSelected = ReferenceEquals(source, _activeTab);

    if (draggingSelected || selectedRoot == null)
    {
        // 선택된 탭을 드래그 → Seam 완전 숨김
        SelectedTabSeam.RenderTransform = null;
        SelectedTabSeam.Visibility = Visibility.Collapsed;
    }
    else
    {
        // 비선택 탭 드래그 → Seam을 선택 탭에 붙여 따라가게
        SelectedTabSeam.RenderTransform = GetOrCreateTranslate(selectedRoot);
    }
}

private static TranslateTransform GetOrCreateTranslate(UIElement el)
{
    if (el.RenderTransform is TranslateTransform t) return t;
    if (el.RenderTransform is TransformGroup g)
    {
        var ex = g.Children.OfType<TranslateTransform>().FirstOrDefault();
        if (ex != null) return ex;
        var added = new TranslateTransform();
        g.Children.Add(added);
        return added;
    }
    var nt = new TranslateTransform();
    if (el.RenderTransform != null && el.RenderTransform != Transform.Identity)
    {
        var grp = new TransformGroup();
        grp.Children.Add(el.RenderTransform);
        grp.Children.Add(nt);
        el.RenderTransform = grp;
    }
    else el.RenderTransform = nt;
    return nt;
}
```

### 8.10 EndTabDragAsync

```csharp
private async Task EndTabDragAsync()
{
    var td = _tabDrag;
    _tabDrag = null;
    _pendingTab = null;
    var screen = TabsHost.PointToScreen(Mouse.GetPosition(TabsHost));
    if (Mouse.Captured == TabsHost) TabsHost.ReleaseMouseCapture();
    RestoreTabFeet();

    if (td != null)
    {
        // 반대 패널 위면 크로스 드래그 커밋, 아니면 내부 재정렬
        bool crossed = TryCommitCrossDrop?.Invoke(this, td.Source, screen) == true;
        await td.FinishAsync(commit: !crossed);
    }
    SetPanesTabDragActive?.Invoke(false); // +버튼 복원
}
```
