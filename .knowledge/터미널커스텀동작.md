# 터미널 커스텀 동작 규칙

DevezCode 터미널은 **WebView2 + xterm.js 5.5.0** 로 렌더한다. 모든 커스텀 입력/마우스/클립보드/IME 동작은 두 파일에 집중돼 있다.

- **프론트엔드**: `Resources/Terminal/web/terminal.html` (xterm, 키/마우스/클립보드/IME/스크롤)
- **호스트(C#)**: `Views/TerminalHostView.cs` (JS↔WPF 브리지, 실제 클립보드 Win32, 폰트/세션 액션)

> **핵심 제약**: WebView2 는 `HwndHost` 라 항상 WPF 위에 그려진다(airspace). WPF 오버레이·`PreviewMouseDown` 이 터미널 표면을 못 덮고/못 본다. → 오버레이(로딩/커튼/토스트)와 클릭 포커스 통지는 **반드시 웹 레이어 안**에서 처리한다.

기준선은 **Windows Terminal(WT) 정합**. 아래 동작은 대부분 "WT 와 똑같이"가 목표다.

## 1. 키보드 단축키

`handleKey()` (terminal.html:385) 이 `attachCustomKeyEventHandler` 로 가로챈다.
규약: **`false` 반환 = xterm 처리 안 함(PTY 전송 차단)**, **`true` = 셸/에이전트로 그대로 전달**. 우리가 가로채는 키만 `false`.

| 단축키 | 동작 | 비고 (파일:라인) |
|---|---|---|
| **Ctrl+Enter** / Ctrl+NumpadEnter | 줄바꿈 삽입(제출 X) | 조합 중에도 동작. 에이전트별 시퀀스 상이 ↓ (`:390`) |
| **Ctrl+C** | 선택 있으면 **복사 + 선택 해제**, 없으면 SIGINT(`\x03`) 통과 | gjc grace 예외 ↓ (`:415`) |
| **Ctrl+Shift+C** / Ctrl+Insert | 복사 (선택 없으면 PTY 통과) | (`:430`) |
| **Ctrl+V** / Ctrl+Shift+V / Shift+Insert | 붙여넣기(`requestPaste`) | WT 기본대로 Ctrl+V 도 붙여넣기 (`:436`) |
| **Ctrl+Shift+F** | 터미널 내 검색바 열기 | (`:442`) |
| **Ctrl+Shift+A** | 전체 선택(`selectAll`) | (`:446`) |
| **Ctrl + `=`/`+`/Add** | 폰트 확대 | (`:452`) |
| **Ctrl + `-`/`_`/Subtract** | 폰트 축소 | (`:453`) |
| **Ctrl+0** | 폰트 크기 리셋 | (`:454`) |
| **Ctrl+Shift+↑ / ↓** | 1줄 스크롤 | (`:458`) |
| **Shift+PageUp / PageDown** | 1페이지 스크롤 | (`:460`) |
| **Ctrl+Shift+Home / End** | 맨 위 / 맨 아래로 스크롤 | (`:462`) |
| **Ctrl+Shift+T** / Ctrl+Shift+D | 새 세션 | C# `SessionActionRequested` 위임 (`:466`) |
| **Ctrl+Shift+W** | 세션 닫기 | (`:469`) |
| **Ctrl+Tab / Ctrl+Shift+Tab** | 다음 / 이전 세션 | (`:472`) |
| **Ctrl+Alt+1..9** | N번째 세션 이동 (9 = 마지막) | 물리 키(`e.code=Digit1..9`) 기준, 레이아웃 비의존 (`:477`) |

### Ctrl+Enter 줄바꿈 시퀀스 (에이전트별)
`ctrlEnterNewlineData()` (`:379`):
- **gajae(gjc)**: raw LF `\n` — gjc TUI 는 `\x1b\r` 을 Alt+Enter(queue)로 오인
- **claude / opencode / 셸**: `\x1b\r` (WT 정합)

### IME 조합 중 Ctrl+Enter
조합 중 눌리면 줄바꿈을 **먼저 보내지 않고** `compositionend` 로 미룬다(`pendingComposeNewline`, `:362`/`:394`). 먼저 보내면 줄바꿈이 확정 글자보다 앞서 PTY 도달 → 마지막 글자가 새 줄로 내려감.
한글 확정 Enter 는 keydown 이 2번(229=조합중 → 13=확정) 오므로, `composeEnterAt` 로 200ms 내 따라오는 비조합 Enter 를 흡수해 줄바꿈 중복 차단(`:401`).

### 가로채기 가드
- **IME 조합 중**(`isComposing` 또는 `keyCode===229`): Ctrl+Enter 특례만 처리하고 나머지는 전부 통과(`:405`)
- **AltGr**(`getModifierState('AltGraph')`): 문자 입력 → 가로채지 않음(`:406`)
- **죽은 세션**(`entry.dead`): Ctrl+Enter 는 통과. (죽은 세션에서 Enter = 재시작 요청, `onData` `:773`)

## 2. 마우스 동작

| 입력 | 동작 | 비고 (파일:라인) |
|---|---|---|
| **좌 드래그** | 텍스트 선택 | TUI 마우스 모드에선 **Shift+드래그** 필요 |
| **좌 드래그 후 뗌(mouseup)** | **copy-on-select** — 자동 복사, 선택 하이라이트 유지 | `doCopyKeep`, 다음 프레임에 조회 (`:759`) |
| **우클릭(누르는 즉시, mousedown)** | 선택 있으면 **복사**, 없으면 **붙여넣기** | WT 정합. 누름 1회 처리(뗄 때 추가 없음) (`:599`) |
| **컨텍스트 메뉴** | 항상 차단(`preventDefault`) | (`:607`) |
| **Ctrl+휠** | 폰트 확대(위)/축소(아래) | capture + `passive:false` 로 xterm 스크롤보다 먼저 가로챔 (`:558`) |
| **일반 휠** | xterm 스크롤백 스크롤 | 아래로 굴려 바닥 근처면 ybase 스냅(nudge) (`:578`) |
| **아무 곳 mousedown** | `interact` 통지 → 호스트 패널 포커스 승격 | WebView2 HWND 가 WPF 로 클릭 전파 못 함 (`:600`) |
| **Ctrl+클릭(파일 경로)** | 에디터 탭으로 파일 열기(`openFile`) | linkProvider 확장자 정규식 매칭, `ctrlKey`/`metaKey` 필수 (`:649`) |
| **중클릭** | 특별 처리 없음 → xterm/PTY 기본 | button===2 만 처리 |

### 마우스 트래킹 모드 (TUI)
- **claude 등**: DECSET `?1000/1002/1003/1006` 을 **막지 않고 통과**시킨다(`:280`). → 마우스 클릭/드래그/휠이 앱으로 직접 전달(WT 정합). 드래그 선택은 claude 자체가 하고 OSC 52 로 복사.
- **gjc**: 마우스 모드 DECSET 을 **파서 단계에서 삼킨다**(`swallowMouse`, `:701`). gjc 는 마우스 트래킹을 무조건 켜지만 자체 선택 렌더가 없어, 삼켜서 항상 **xterm 로컬 선택**을 쓰게 함 → 드래그 하이라이트 + copy-on-select 복원. 삼키는 모드: `1000,1001,1002,1003,1005,1006,1015,1016`. 그 외 DECSET(`?2004/?2026/?25/?1049`)은 통과.

### 우버튼 SGR 리포트 중복 방지
TUI 마우스 모드에선 xterm 이 우버튼 SGR 리포트(`ESC[<2..M/m`)도 PTY 로 보내는데, claude 가 이를 받아 **또** 붙여넣기 → 2회 붙여넣기. `onData` 에서 우버튼 리포트만 걸러 전달 안 함(`:780`). 판정: `(b&3)===2 && b<64`(우버튼, 휠 제외). 좌/중/휠/모션은 보존.

## 3. 클립보드

### 복사 (JS → C#)
- **경로**: 선택 복사(Ctrl+C / 우클릭 / copy-on-select) → `post({type:'copy'})` → C# `SetClipboardText`
- **C# 구현**(`TerminalHostView.cs:728`): WPF `Clipboard.SetDataObject` 대신 **Win32 직접**(`OpenClipboard`/`EmptyClipboard`/`SetClipboardData(CF_UNICODETEXT)`) 을 **STA 스레드**에서. 이유: WPF 경로는 `OleFlushClipboard` 라 클립보드 뷰어 체인/후킹 앱과 데드락. 점유 시 즉시 반환 + 재시도.

### 붙여넣기 (요청 → C# 읽기 → JS 주입)
- Ctrl+V 등 / 우클릭 → `post({type:'requestPaste'})` → C# `ReadClipboardForPaste`(STA, 8회 재시도, `:853`) → `post({type:'paste'})` → `term.paste()`
- **이미지 우선**: 클립보드에 Bitmap 있으면 `%TEMP%\DevezCode\clipboard\clip_<ts>.png` 로 저장 후 **파일 경로**를 붙여넣음(claude 이미지 첨부용, `:862`). 없으면 UnicodeText → Text.

### OSC 52 (TUI 복사 → 실제 클립보드)
- claude/gjc 등이 선택 후 `ESC]52;c;<base64>` 로 복사할 때, 번들 xterm 은 기본 무시(토스트만 뜨고 실제 복사 안 됨). → `registerOscHandler(52)` 로 직접 처리해 Windows 클립보드에 기록(`:681`).
- **쓰기만** honor. 읽기 질의(payload `?`)는 보안상 무시.

### 복사 토스트
"copied N chars to clipboard" 를 우측 하단에 잠깐 표시(`showCopyToast`, `:491`). **우리가 직접 복사한 경로에서만**(Ctrl+C/우클릭/copy-on-select/gjc grace). claude 네이티브 복사는 OSC52 라 claude 자체 토스트가 떠서 여기선 안 띄움(중복 방지).

## 4. 에이전트별 특수 처리 요약

| | claude | opencode | gjc(가재코드) |
|---|---|---|---|
| Ctrl+Enter 줄바꿈 | `\x1b\r` | `\x1b\r` | `\n` |
| 마우스 모드 | 통과(앱이 처리) | 통과 | **삼킴**(xterm 로컬 선택) |
| 드래그 선택 | claude 자체 + OSC52 | (셸/앱) | xterm 로컬 + copy-on-select |
| 선택색 | 테마 기본 | 테마 기본 | **gjc 전용 오버라이드** ↓ |
| 스크롤백 클리어(CSI 3J) | 기본 | 기본 | **삼킴**(param==3만) ↓ |

### gjc 선택색 (`gjcSelectionBg`, `:306`)
gjc 는 xterm 로컬 선택을 쓰므로 `selectionBackground` 만 테마별로 덮음(`selectionForeground` 는 안 건드림 — 색기반 볼드 보존):
- soft(`#f2ede6`) → `#C2D8B0`
- minimal(`#f8fafc`) → `#C5D8F8`
- dark(그 외) → `#264F78`

### gjc Ctrl+C grace (`:420`)
gjc 는 생성 중 고빈도 풀 재페인트(`\x1b[2J`)가 xterm 선택을 지운다 → 드래그 직후 Ctrl+C 가 선택을 못 봐 SIGINT 로 빠져 gjc 중단됨. **최근 선택(800ms grace)** 이 있으면 그걸 복사하고 SIGINT 억제(`onSelectionChange` 로 `lastSelText`/`lastSelAt` 기록, `:751`). 한 번 더/grace 밖이면 정상 인터럽트.

### gjc 스크롤백 클리어 삼킴 (`:712`)
gjc(비멀티플렉서)는 풀 재페인트 때 `\x1b[3J` 로 스크롤백을 비운다 → 첫 휠 시 뷰포트가 맨 위로 튐. `param==3` 만 삼키고 ED 0/1/2(화면 지움)는 통과 → 과거 대화 스크롤 보존.

## 5. IME (한글 조합)

- **조합 위치 고정**(`setupImeCaretFix`, `:321`): claude 는 하드웨어 커서를 화면 끝에 파킹해 조합 글자가 엉뚱한 곳에 뜬다. 버퍼에서 블록커서(반전 빈 셀)를 찾아 `--ime-left/--ime-top` CSS 변수로 조합뷰+helper-textarea 위치를 강제(`.ime-fixed`, css `:42`). xterm 이 0ms 루프로 인라인 위치를 되돌리므로 `!important` CSS 변수로 무력화.
- **조합뷰 스타일**(css `:30`): WT 정합 — 전경색 글자 + 밑줄, **불투명 배경**(아래 블록커서 비침 방지).
- **절대 `display:none` 금지**: 조합용 textarea 크기가 0 되면 조합 자체가 끊김(한글 입력 불가).
- **포커스 리포팅(DEC 1004) 억제**(C# `:457`): 조합 시 helper-textarea blur 로 xterm 이 focus-out(`ESC[O`) 보내면 claude 가 커서를 치움 → 조합 글자 날아감. `ESC[O`/`ESC[I` 를 세션에 전달 안 함.
- **한글 폴백 폰트**: `..., 'D2Coding', 'NanumGothicCoding', 'Malgun Gothic', monospace`(`:617`).

> 텍스트 렌더링/글자 깨짐 관련은 `.knowledge/텍스트렌더링규칙.md` 도 함께 참조.

## 6. 입력 부가 신호 (C# `OnWebMessageReceived`)

- **단독 ESC(`\x1b`)** → `InterruptRequested`(스피너 무한 회전 방지 위해 즉시 busy 해제) + 입력은 그대로 전달(`:461`)
- **선택지 제출(Enter / 숫자 1~9)** → `MenuInputSubmitted`(입력 대기 ❗ 해제). 화살표 등 네비게이션은 제외(`:464`)
- **죽은 세션 Enter** → `restart`(`:773`)

## 7. 스크롤 / 렌더링 커스터마이즈 (참고)

- **near-bottom sticky follow**(`writeOut`, `:265`): 쓰기 직전 바닥 2줄 이내면 쓴 뒤 맨 아래로 붙임(gjc 재페인트로 추종 끊김 방지). 위로 읽는 중엔 개입 안 함.
- **`_scrollSuppress`**(`suppressScroll`, `:922`): 슬래시 명령 자동주입(/model·/effort) 후 N회 출력 동안 스크롤 위치 유지. 사용자가 휠 굴리면 즉시 해제(`:571`). 1.5s 후 강제 0.
- **`_pinBottomUntil`**(`pinBottom`, `:929`): 인라인 TUI(gjc) resume 재페인트 스크롤 튐 방지 — 지정 시각까지 쓰기 후 항상 맨 아래.
- **동기화 업데이트(?2026) 배칭**(`feedSync`, `:215`): gjc 멀티플렉서 repaint 를 open~close 한 번의 write 로 모아 입력창 튐 제거. 마커가 chunk 경계에서 잘리면 `syncCarry` 로 보류.
- **WebGL 렌더러**(`:638`): GPU 렌더. 소수 배율(125/150%)에선 커서 렌더 버그 → DOM 렌더러로 폴백(`disposeWebglIfFractional`, `:867`). GPU 컨텍스트 로스 시 자동 폴백. 원격/소프트웨어 렌더링에선 비활성.
- **전환 커튼(`xferCover`/`xferReveal`/`fadeNow`/`returnResync`)**: 분할·패널 토글 리플로우 깜빡임을 웹 레이어 단색/이미지 커버로 감춤. `_fitSuppressed` 로 중간 폭 fit 억제 → 최종 폭에서 한 번만 fit. (airspace 관련 상세는 커밋 히스토리·`airspace 깜빡임` 문서 참조)

## 8. 주의사항 (수정 시)

1. **`handleKey` 반환값 규약 절대 혼동 금지**: `false`=차단, `true`=통과. 새 단축키 추가 시 IME/AltGr 가드(`:405`) **뒤**에 두되, Ctrl+Enter 특례는 그 **앞**에 유지.
2. **마우스 모드 통과 정책**: claude 등의 DECSET 을 함부로 삼키지 말 것(휠/클릭 전달 깨짐). gjc 만 예외.
3. **클립보드는 반드시 STA + Win32 경로**: WPF `Clipboard.*` 직접 호출 금지(후킹 앱 데드락).
4. **오버레이·포커스는 웹 레이어 안에서만**: WebView2 airspace 때문에 WPF 오버레이로 터미널 못 덮음.
5. **조합뷰 `display:none` 금지**, 포커스 리포팅 억제 유지 — 안 그러면 한글 입력 깨짐.
6. **`Resources/Terminal/web/terminal.html` 이 원본**. `bin/` 은 빌드 복사본이니 편집 금지.
