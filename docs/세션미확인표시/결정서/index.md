# 세션 미확인 표시 결정서

## 목적

여러 세션을 동시에 돌리며 오갈 때, **응답이 끝났거나 입력을 기다리는데 사용자가 아직 보지 않은 세션**을 사이드바와 탭에서 바로 알아볼 수 있게 한다.

성공 기준은 다음과 같다.

- 펼친 프로젝트에서는 세션 행만 훑어봐도 미확인 세션이 구별된다.
- 접힌 프로젝트·폴더에서도 펼치지 않고 미확인 세션이 있는지와 몇 개인지 알 수 있다.
- 사용자가 실제로 보지 못한 완료는 미확인으로 남는다.
