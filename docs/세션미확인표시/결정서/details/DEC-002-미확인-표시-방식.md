# DEC-002 미확인 표시 방식

## 목적과 성공 기준

DEC-001로 정한 미확인 세션을 어디서나 바로 알아볼 수 있게 보여준다.

- 세션 행을 훑기만 해도 미확인 세션이 선택된 세션, 마우스를 올린 세션과 구별된다.
- 여러 행이 동시에 미확인이어도 화면이 어지럽지 않다.
- 접힌 프로젝트·폴더를 펼치지 않고도 미확인 세션 수를 안다.

## 제약과 기존 결정

- 상태 아이콘 자리(점·스피너·❗·숨김·외부 아이콘)는 이미 의미가 정해져 있으므로 건드리지 않는다.
- 접힌 프로젝트·폴더 카드는 안에서 작업 중이면 스피너를 보여준다. 이 표시는 유지하고 함께 보이게 한다.
- 디자인 시스템 규칙대로 화면에 HEX를 직접 쓰지 않고 테마 토큰을 쓴다. 강조 위 글자는 대비 4.5:1 이상을 지킨다.

## 영향을 받는 구성요소

- 사이드바 세션 행
- 패널 탭바의 세션 탭
- 사이드바 프로젝트 카드(접힘 상태)
- 사이드바 프로젝트 폴더 카드(접힘 상태)
- 테마 토큰

## 선택한 방향과 판단 근거

**세션 행과 탭**: 기존의 옅은 깜빡임을 없애고, **진해진 배경색을 고정으로** 깐다. 색은 테마의 강조색 계열이며, 배경은 글자 뒤에 깔려 글자 색을 바꾸지 않는다.

근거: 사용자 선택("배경색 애니메이션 넣지 말고 진하게 변한 색 고정"). 고정색은 여러 행이 동시에 미확인이어도 어지럽지 않고, 깜빡임의 어두운 순간에 놓치는 일이 없다.

**농도는 테마마다 다르게 정한다.** 일부 테마(minimal, softpink, midnight)는 "선택된 세션" 배경이 이미 강조색 계열이라, 같은 농도를 쓰면 미확인과 선택이 거의 같은 색이 된다. 테마마다 아래 세 조건을 만족하는 최소 농도를 쓴다.

- 기본 행 배경과 확실히 구별된다.
- 선택된 세션 배경과 확실히 구별된다.
- 본문 글자와의 대비가 4.5:1 이상이다.

| 테마 | 강조색 농도 |
|---|---:|
| minimal | 28% |
| soft | 34% |
| gray | 30% |
| softpink | 44% |
| dark | 24% |
| midnight | 30% |

**접힌 프로젝트 카드**: 프로젝트 이름 옆에 **미확인 세션 개수를 숫자 배지로** 표시한다. 작업 중 스피너와 동시에 보일 수 있다.

근거: 사용자 선택("미확인 개수 숫자"). 돌고 있는 것(스피너)과 끝난 것(숫자)을 한 카드에서 동시에 구별할 수 있다.

## 적용 범위와 제외 범위

- 적용: 활성 프로젝트 목록과 보관함 목록 모두.
- 제외: 펼친 프로젝트 카드에는 숫자를 표시하지 않는다(세션 행에서 바로 보이므로). 파일·브라우저 탭.

## MECE 조건·예외 분기

| 상황 | 세션 행·탭 | 접힌 프로젝트 카드 | 접힌 폴더 카드 |
|---|---|---|---|
| 미확인 세션 없음 | 평소 배경 | 숫자 없음 | 숫자 없음 |
| 미확인, 선택되지 않은 세션 | 미확인 배경 | 개수에 포함 | 개수에 포함 |
| 미확인이면서 선택된 세션(포커스 안 된 패널, 창이 뒤에 있던 경우) | 선택 배경 위에 미확인 색이 겹쳐 더 진하게 | 개수에 포함 | 개수에 포함 |
| 미확인 세션에 마우스를 올림 | 마우스 배경 위에 미확인 색이 겹침 | — | — |
| 숨긴 세션 | 표시 없음(숨기면 해제) | 개수에서 제외 | 개수에서 제외 |
| 프로젝트가 펼쳐짐 | 행에서 표시 | 숫자 없음 | 폴더가 접혀 있으면 표시 |
| 미확인과 작업 중이 함께 있음 | 각 행에서 각자 표시 | 스피너와 숫자 동시 표시 | 스피너와 숫자 동시 표시 |

## AI가 둔 가정

- **접힌 폴더 카드에도 같은 숫자를 표시한다.** 폴더가 접히면 안의 프로젝트 카드가 통째로 안 보여, 프로젝트 카드에만 숫자를 두면 같은 구멍이 남는다. 폴더 카드는 이미 작업 중 스피너를 같은 방식으로 보여주고 있어 같은 규칙을 따른다. 폴더의 숫자는 안에 든 프로젝트들의 미확인 세션 수 합계다.
- **탭에도 세션 행과 같은 고정 배경을 쓴다.** 사용자 선택은 세션 행 기준이었지만, 탭도 지금 같은 깜빡임을 쓰고 있어 함께 바꾸는 것이 일관된다고 판단했다.
- **숫자 배지 색은 앱에 이미 있는 개수 배지 토큰을 쓴다.** 테마별로 강조색을 밝힌 배경과, 그 위에서 대비가 맞는 글자색이 이미 계산되어 있다.

## 사용자 결정이 필요한 항목

없음 (표시 방식은 2026-10-02 사용자 선택: 세션 행 "진하게 고정", 접힌 카드 "미확인 개수 숫자")

## 결정의 검증 조건

- 여섯 테마 모두에서 미확인 행이 선택된 행·마우스 올린 행과 눈으로 구별된다.
- 미확인 행의 글자가 평소처럼 읽힌다.
- 접힌 프로젝트 카드와 접힌 폴더 카드에 숫자가 나타나고, 세션을 확인할 때마다 줄어들며, 0이 되면 사라진다.
- 작업 중인 세션과 미확인 세션이 함께 있으면 스피너와 숫자가 동시에 보인다.
