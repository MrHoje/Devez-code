# DEC-001 미확인 상태의 발생과 해제

## 목적과 성공 기준

세션이 응답을 끝내거나 입력 대기에 들어간 순간을 사용자가 실제로 봤는지에 따라 "미확인" 여부를 정한다.
사용자가 자리를 비운 사이 끝난 세션, 분할 화면의 반대쪽 패널에서 끝난 세션을 놓치지 않는 것이 성공 기준이다.

## 제약과 기존 결정

- 완료와 입력 대기는 앱이 이미 "확정"하는 지점이 있다(서브에이전트가 잠깐 쉬는 가짜 완료는 걸러진 지점). 미확인 상태도 이 확정 지점에서만 켠다. 확정 전의 순간적인 상태 변화에는 반응하지 않는다.
- 기존에는 "그 세션이 어느 패널에든 열려 있으면 본 것"으로 쳤다. 이 결정으로 그 기준을 좁힌다.
- 토스트 알림과 작업표시줄 깜빡임은 이 결정의 범위가 아니며 기존 동작을 유지한다.

## 영향을 받는 구성요소

- 세션 완료·입력 대기 확정 지점
- 세션을 화면에 띄우는 동작(탭 클릭, 사이드바 행 클릭, 프로젝트 선택 시 직전 세션 복원, 알림 클릭, 단축키 이동)
- 터미널 화면·Claude GUI 화면의 사용자 조작
- 세션 숨기기

## 선택한 방향과 판단 근거

**미확인이 켜지는 시점**: 완료 또는 입력 대기가 확정되는 순간, 아래 세 조건을 **모두** 만족하지 않으면 미확인으로 표시한다.

1. 앱 창이 앞에 있다(활성 창이고 최소화되지 않았다).
2. 그 세션이 **포커스된 패널**의 현재 화면이다(파일·브라우저 탭을 보고 있으면 세션을 보는 것이 아니다).
3. 그 세션이 숨김 상태가 아니다.

근거: 사용자가 선택한 기준은 "실제로 보고 있을 때만 확인으로 친다"이다. 창이 뒤에 있거나 다른 패널을 보고 있으면 그 순간을 보지 못했다고 판단한다.

**미확인이 꺼지는 시점**: 다음 중 하나가 일어나면 해제한다.

- 그 세션을 화면에 띄운다(탭·행 클릭, 프로젝트 선택으로 복원, 알림 클릭, 단축키 이동 등).
- 그 세션이 떠 있는 패널의 터미널·Claude GUI 화면을 클릭하거나 키를 입력한다.
- 그 세션을 숨긴다.

근거: 사용자가 고른 선택지 설명대로, 탭을 열어 둔 채 다른 창에 다녀온 경우는 미확인으로 남고, 돌아와서 그 패널을 조작해야 꺼진다. 창이 다시 앞으로 오는 것만으로는 해제하지 않는다.

## 적용 범위와 제외 범위

- 적용: 모든 에이전트 세션(터미널 세션, Claude GUI 세션, 외부 터미널로 넘긴 세션 포함).
- 제외: 파일 탭, 브라우저 탭. 앱 재시작 후의 복원.

## MECE 조건·예외 분기

| 끝나는 순간의 상황 | 결과 |
|---|---|
| 창이 앞에 있고, 포커스된 패널에 그 세션이 떠 있음 | 본 것 — 표시하지 않음 |
| 창이 앞에 있고, 분할 화면의 포커스되지 않은 패널에 떠 있음 | 미확인 |
| 창이 앞에 있고, 어느 패널에도 떠 있지 않음 | 미확인 |
| 창이 앞에 있고, 포커스된 패널이 파일·브라우저 탭을 보는 중 | 미확인 |
| 창이 뒤에 있거나 최소화됨(그 세션이 떠 있어도) | 미확인 |
| 앱 위에 뜬 다른 창(미니 브라우저, 대화상자)을 보고 있음 | 미확인 (메인 창이 활성 창이 아니므로) |
| 세션이 숨김 상태 | 표시하지 않음 |
| 이미 미확인인 세션이 다시 완료·대기 | 미확인 유지 |

## AI가 둔 가정

- **앱을 다시 켜면 미확인 상태는 사라진다.** 기존 펄스와 같이 저장하지 않는다. 재시작 직후에는 모든 세션이 꺼져 있다가 다시 붙기 때문에, 이전 상태를 되살려도 의미가 약하다고 판단했다.
- **세션을 화면에 띄우는 동작은 모두 확인으로 친다.** 사용자가 직접 누르지 않았더라도(탭을 닫아 옆 탭이 자동으로 뜨는 경우 등) 화면에 올라온 것으로 본다.
- **숨기기는 확인으로 친다.** 숨기는 것은 그 세션을 일부러 치우는 동작이므로, 숨김 영역에서 미확인 표시가 남지 않게 한다.
- **입력 대기(❗) 진입도 미확인 대상이다.** 기존 펄스와 같은 대상이다. ❗ 아이콘은 이와 별개로 응답할 때까지 유지된다.

## 사용자 결정이 필요한 항목

없음 (확인 기준은 2026-10-02 사용자 선택: "실제로 보고 있을 때만")

## 결정의 검증 조건

- 창을 앞에 두고 포커스된 패널에서 보던 세션이 끝나면 표시가 생기지 않는다.
- 다른 창으로 전환한 뒤 그 세션이 끝나면, 돌아왔을 때 표시가 남아 있고, 그 터미널을 클릭하거나 키를 누르면 사라진다.
- 분할 화면에서 포커스되지 않은 쪽 세션이 끝나면 표시가 생기고, 그 패널을 클릭하면 사라진다.
- 사이드바에서 다른 세션을 열면 그 세션의 표시가 사라진다.
