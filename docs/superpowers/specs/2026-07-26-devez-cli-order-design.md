# Devez CLI 표시 순서

## 목표

`Devez CLI`를 모든 에이전트 목록의 마지막 항목으로 표시한다. 대상에는 설정 > 에이전트와 세션 생성 피커가 포함된다.

## 설계

에이전트의 공통 표시 순서는 `AgentRegistry.All`이 정의한다. `devezcli` 정의를 이 배열의 마지막으로 이동한다. 각 UI는 이 순서를 소비하므로 별도 화면별 정렬은 추가하지 않는다.

## 영향과 보존 사항

- `Devez CLI`의 식별자, 미리보기 잠금, 설치 감지, 실행/복원 동작은 변경하지 않는다.
- 다른 에이전트의 상대 순서는 유지한다.
- 설정 화면과 세션 생성 피커 외에 공통 레지스트리 순서를 사용하는 화면도 같은 순서를 따른다.

## 검증

- 코드에서 `devezcli` 항목이 `AgentRegistry.All`의 마지막인지 확인한다.
- Release 빌드로 컴파일을 확인한다.
